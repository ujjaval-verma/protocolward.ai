# Security Policy

## Reporting a vulnerability

**Do not file public GitHub issues for security vulnerabilities.**

Email **security@protocolward.ai**. Contact details are also published at https://protocolward.ai/.well-known/security.txt.

Protocol Ward is in public beta. We still treat every report seriously and credit reporters.

## Disclosure timeline

We follow a 90-day coordinated disclosure window from the initial report. Extensions are negotiated case by case when a fix needs substantial coordination.

## Credit

With your permission, reporters are credited publicly once a fix ships and the embargo lifts.

## Scope

In scope: code in this repository, official release artifacts, the signed update path (`ward update`), the WebAssembly demo build, and the protocolward.ai site.

Out of scope: third-party blocklist sources (report upstream), and bugs in dependencies that are not exploitable in our usage (still appreciated, but route them upstream first).
